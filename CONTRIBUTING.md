# Contributing to OAE Core

Create focused pull requests that include implementation, regression tests, documentation, and an entry in `CHANGELOG.md` when behavior changes. Run `ruff check src tests`, `mypy src`, and `pytest --cov=oae --cov-fail-under=70` before requesting review.

Request at least one reviewer for production-facing changes. Repository owners should keep branch protection configured to require pull requests and review before merge where the team workflow permits it. Do not manufacture contributor history; durable maintenance evidence must come from real work by real contributors over time.
