## Overview

OAE (Open Autonomous Engineer) is a repository-aware engineering platform designed to help AI systems understand, plan, verify and safely improve software systems.

Unlike traditional AI coding assistants that focus on generating code, OAE is being engineered as a complete software engineering operating system with governance, verification, repository awareness and human oversight built into its core architecture.

The long-term vision is to enable AI agents to perform autonomous engineering work safely, transparently and responsibly.

---

# Vision

Build the world's most trusted autonomous engineering operating system.

OAE aims to become an engineering platform capable of understanding software repositories, planning engineering work, executing implementation tasks, validating results and continuously improving software while maintaining security, governance and human control.
