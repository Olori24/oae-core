# OAE (Open Autonomous Engineer)

> Autonomous Engineering Operating System

OAE is a repository-aware engineering platform designed to help AI agents understand, plan, verify, and safely improve software systems.

---

## Vision

Build the safest autonomous engineering operating system capable of assisting developers across the complete software lifecycle while maintaining governance, security, and human oversight.

---

## Current Status

**Version:** v0.3.0-alpha

OAE is under active development.

Current focus:

- Repository Intelligence
