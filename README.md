## What is OAE™?

OAE™ (Open Autonomous Engineer) is an autonomous engineering operating system designed to help AI systems understand repositories, discover engineering problems, generate implementation plans, safely improve software, verify results, and continuously evolve software systems under human approval.

Unlike traditional AI coding assistants that focus primarily on code generation, OAE™ is engineered as a repository-aware engineering platform with governance, verification, safety controls, memory, planning, execution, and continuous improvement.

## Benchmarking

OAE™ is validated against real software repositories rather than synthetic examples alone. Opportunity Radar Africa is an early benchmark for the autonomous engineering improvement loop.

The project records engineering outcomes and verification evidence rather than treating a generated change as successful merely because it was produced.

## Development Standard

Every substantive capability should follow:

1. Design
2. Architecture decision
3. Implementation
4. Automated testing
5. Verification
6. Documentation
7. Re-analysis

Changes must preserve existing behaviour unless a contract change is deliberate and verified.

## Testing

Run the project's automated test suite from the repository environment:

```bash
pytest
```

A test count is not considered a quality claim unless it is supported by an actual verification run.
